## Lab 5 - URL-based access control can be circumvented  
**End Goal** - Access Admin Panel and Delete the user called Carlos.  
  
---
### Analysis:  
Given:  
-> The application has an Admin Panel at `/admin`.  
-> The frontend blocks the access to the path but the backend supports a Header like this `X-Original-URL:`  
  
- I already had an Admin Panel button, when i accessed the lab.  
  
- I Clicked on the Admin Panel button but it just shows `Access Denied`, a very plain looking response. and because of this we know that this response is generated by a frontend framework, because it doesn't have access to any themes/styles of the application from the backend.  
 
- To check if the application accepts the response using a header like `X-Original-URL:`, i sent this request:  

    Focus on this 2 lines:
    ```http
    GET /admin HTTP/2
    X-Original-Url: /admin
    ```  
    it didn't work and again the frontend blocked it.   
  
- So i gave a path that i can access normally, and gave it like this:  
    ```http
    GET /admin HTTP/2
    X-Original-Url: /login
    ```  
    again the frontend blocked it, this means currently it is looking at this path `GET /admin` to block it.  
      
- So now i gave a path in the `GET req` that is accessible normally, and gave the blocked path in the `X-Original-URL:`  
    ```http
    GET / HTTP/2
    X-Original-Url: /admin
    ```  
    Now i was able to access the Admin Panel.  
      
- Then i just sent that response to the browser and i tried to delete the user called Carlos, and it says access denied, because we have to give that `X-Original-URL:` header again for this request of deleting a user.  
  
- The req looked like this `GET /admin/delete?username=carlos`, so again i did:  
   ```http
    GET /
    X-Original-Url: /admin/delete?username=carlos
    ```  
    but this time the response says `missing parameter 'username'` but i already gave the parameter username as carlos.  
      
- But we had to give the parameter in the `GET req itself`, even if we give the path in the `X-Original-Url:`, so now i send this req:  
   ```http
    GET /?username=carlos
    X-Original-Url: /admin/delete
    ```  

- Now the User named as Carlos got deleted.
